# Evergreen Auto — Military EV Modernization Website

Static six-page HTML/CSS/JavaScript website for GitHub Pages.

## Positioning
Evergreen Auto is presented as developing a **concept** for Slate-based electric truck modernization for non-weaponized U.S. military installation and field-support applications. The copy focuses on installation utility, logistics, maintenance, vehicle integration, sustainment, and EV charging.

## Pages
- `index.html` — Main
- `sales.html` — Platform & Sales
- `integration.html` — Vehicle Integration
- `configuration.html` — Vehicle Configuration
- `repair.html` — Repair & Sustainment
- `charging.html` — Evergreen Auto / ChargePoint Charging Infrastructure

## Publish on GitHub Pages
1. Upload the contents of this folder to the repository root.
2. In GitHub, open **Settings → Pages**.
3. Under **Build and deployment**, choose **Deploy from a branch**.
4. Select the branch (usually `main`) and folder `/ (root)`, then Save.

## Before publishing
- Replace `REPLACE-WITH-CONTACT-EMAIL` in `index.html` with the correct contact email.
- Confirm all copy accurately reflects Evergreen Auto's actual capabilities, business status, and authorized relationships.
- The inquiry form opens the visitor's email application; it does not submit to a server.
- Review the use of Slate Auto and ChargePoint names/logos with the respective companies. This website does not imply affiliation, authorization, endorsement, reseller status, or a government contract.
- Obtain written manufacturer approval before representing any Slate vehicle modifications as approved or warranty-compatible.
- Do not publish classified, controlled, export-restricted, or operationally sensitive information through the public website or inquiry form.
- Remote photos are hosted by Unsplash. Replace them with approved Evergreen Auto photography as available.

## Important scope and claims
This site describes a proposed concept, not a qualified or fielded military vehicle. It makes no claim of U.S. government approval, military qualification, Slate Auto authorization, ChargePoint partnership, or proven combat capability. Vehicle availability, technical specifications, modification permissions, payload limits, safety, warranty, and compliance must be confirmed before making product claims or commitments.

No weapons integration or offensive combat-system functionality is described.
